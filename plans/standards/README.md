## Dispositioned without a plan

- The whole-spec header stays `Partial`; there is no preamble marker, so it is not an item of its own. No roadmap, status ledger or stale status cell.
- §11's CSS Containment 3 entry gives a stale reason ("`$media` is viewport-only. Container queries would need a named-container model in the style object"). Container queries, named ones included, already pass through a style object: any `@` key `resolveAtQuery` does not resolve is emitted verbatim as its own at-rule (`walkAt` in packages/runtime/src/css.ts; spec.md §9.2 admits standard at-rules as nested keys, and §9.6 says an authored at-rule "is passed through verbatim"), and Studio ships one, `"@container toolbar (max-width: 1140px)"` in packages/studio/src/surfaces/commandbar.json against the container `shell-frame.css` names. A backlog row carries no status, so this is not an open item here. Forwarded to spec.md: either CSS Containment 3 becomes a row in spec.md §18 binding the section that already carries it, which removes the backlog entry under `backlog-already-cited`, or the entry's "Why not yet" is rewritten to name what is actually absent (for example a `$media`-style alias map for container conditions).
