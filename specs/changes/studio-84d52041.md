The Design workspace ships: the Site panel lists pages by route, templates, components and media; the rail holds Site, Outline and Data with Files and Packages behind Show developer panels; the Inspector is Page, Element and Assistant with a contextual Page title, Element's Content, Style and Logic switch and a selection-driven switch; and component insertion imports the component from every door, a package component included. The Site panel lists installed packages' components after the project's, and the Page tab's header names the document.
