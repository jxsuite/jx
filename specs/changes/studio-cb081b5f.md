The Publish workspace ships: Review changes, Deploys, Branches and Hosting replace the Source Control panel, quick publish opens from the chevron beside the Publish tab, and capability.publish joins the context keys. A change is included the first time Review changes shows it, Send for review is refused on the default branch of a host whose commits land live, Deploys words each deployment's state and re-reads after a deploy, and the Hosting source policy is Pending.
